Build a custom month calendar without a UI framework.

You need a calendar-shaped view: seven columns, the right number of days, and room for your data. You want your own HTML and styling, not a date-picker component's selection model. This is the narrow problem Monthloom solves.

We will build a February 2024 event calendar, then adapt the same dates for booking availability and habits. All event and availability records below are fictional demo data.

Try the working recipes

1. Install and ask for weeks

npm install monthloom

In your project's JavaScript module:

import { getMonthGrid } from 'monthloom';

const weeks = getMonthGrid(2024, 1, { weekStartsOn: 1 });
console.log(weeks[0].map(date => date?.getDate() ?? null));
// [null, null, null, 1, 2, 3, 4]

Months are zero-based, so 1 means February. Each week has seven cells. Cells outside the month are null; the others are local Date objects. Leap-year arithmetic and week padding are handled for you.

The default returns only the required rows. Add fixedWeeks: true for six rows, or showOutsideDays: true for adjacent-month dates. If you show adjacent dates, use a full year-month-day key for records.

2. Render your own markup

Add <div id="calendar"></div> to your HTML. This complete module builds a table, accessible column headers, and event labels. It uses textContent, so event text is not interpreted as HTML.

import { getMonthGrid, getWeekdayLabels } from 'monthloom';

const table = document.createElement('table');
const caption = document.createElement('caption');
caption.textContent = 'February 2024';
table.append(caption);

const head = document.createElement('thead');
const labels = document.createElement('tr');
for (const label of getWeekdayLabels({ weekStartsOn: 1 })) {
  const th = document.createElement('th');
  th.scope = 'col';
  th.textContent = label;
  labels.append(th);
}
head.append(labels);
table.append(head);

const events = new Map([[7, 'Design review'], [22, 'Release day']]);
const body = document.createElement('tbody');
for (const week of getMonthGrid(2024, 1, { weekStartsOn: 1 })) {
  const row = document.createElement('tr');
  for (const date of week) {
    const cell = document.createElement('td');
    if (date) {
      const event = events.get(date.getDate());
      cell.textContent = `${date.getDate()}${event ? ': ' + event : ''}`;
    }
    row.append(cell);
  }
  body.append(row);
}
table.append(body);
document.querySelector('#calendar').replaceChildren(table);

The installed package exports work in bundlers such as Vite. To try this without a bundler, use our hosted example, which loads local browser modules, or clone the repository, run npm ci && npm run build:pages, and serve _site/ with a static HTTP server.

3. Keep application state in your application

For a booking interface, render date buttons and set button.disabled when your availability data marks a date unavailable. Store the selected date yourself. Real reservations still need server-side validation; disabling a browser button is not an availability guarantee.

For a habit tracker, keep completed dates in a Set. A click adds or removes a date, then updates aria-pressed. Our demo uses memory only; choose your own persistence layer if you need one.

For events, look up records while rendering each date. The example uses day numbers because it covers one fixed month. In a multi-month app, use a local date key:

const key = date => [
  String(date.getFullYear()).padStart(4, '0'),
  String(date.getMonth() + 1).padStart(2, '0'),
  String(date.getDate()).padStart(2, '0')
].join('-');

Avoid toISOString().slice(0, 10) for local date keys: it converts the date to UTC, which can change the day.

4. Move between months

import { Calendar } from 'monthloom';

let calendar = new Calendar(new Date(2024, 11, 1));
calendar = calendar.next(); // January 2025
const weeks = calendar.getWeeks({ weekStartsOn: 1 });

next() and previous() return new calendars. Render again when your state changes. In Vue, use shallowRef for this class instance so its private fields are not wrapped in a reactive proxy. The React example and Vue example show full navigation and selection without framework adapter packages.

Know the boundary

Monthloom generates Gregorian calendar data. It does not schedule events, expand recurrence rules, convert time zones, or implement a complete accessible date-picker interaction model. Its optional widget supplies basic month navigation and a date-selection callback.

That small scope is deliberate: use it when you want to own the interface. Choose a full picker or scheduler when you need those behaviors included.
